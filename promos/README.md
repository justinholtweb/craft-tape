# Plugin Store promo images

Marketing images for the Tape listing on the Craft Plugin Store, in the same theme as the plugin's
marketing page at [justinholt.com/plugins/craft-tape](https://justinholt.com/plugins/craft-tape).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output goes to `out/` as `tape-promo-N.jpg`, 1920×1080. Chrome renders each slide at 2× and
`sips` downsamples it, which keeps the type crisp. **Promos are JPEG, never PNG.** Chrome can only
write PNG, so `build.sh` converts at quality 90 and then deletes the PNG. Before calling the deck
done, check that `out/` holds seven `.jpg` files and nothing else.

## Slides

| # | Slide | Shows |
|---|-------|-------|
| 1 | Cover: name, tagline, app icon, price | Lite free · Pro $99, $59/year renewal |
| 2 | Where conversions go missing | the three ways a conversion is lost, and the one way it gets counted twice |
| 3 | One event, two channels, one ID | sources → `TrackingEvent` → browser tag + Conversions API with the same `eventId` → 1 purchase |
| 4 | Thirteen platforms. Paste in the ID. | all 13 platforms plus custom snippet and webhook, with edition and server-side API for each |
| 5 | Unknown is not denied | the three consent states, and the ten consent platforms Tape reads, plus an expression of your own |
| 6 | Finds the orders nobody heard about | **real** screenshot of Tape → Accuracy, with recovery underneath |
| 7 | Every pixel, one screen | **real** screenshot of Tape → Destinations |

Every claim comes from the plugin README and the marketing-page copy. If you change one, change
the other. Two facts are easy to get wrong:

- Platform tiles on slide 4 follow the README's "Where it sends" table: edition, and whether there
  is a server-side API.
- Pricing is Lite free, Pro $99 with a $59/year renewal. A renewal that lapses stops updates only,
  and Pro keeps working. Don't say that Pro destinations stop firing.

## Palette

The background is the site's dark warm ink, `#15100B` → `#1C140D`, with cream `#FFF8F0` text. The
icon's tile brown `#8F551E` is used only for **fills**: the price badge, the highlighted cards, the
gradients. As text on ink it is too dark to read, which is the same problem the Chunky deck had
with its berry. Eyebrows, rules, check marks and code use the light accent `#E0A060`, and
`#C7843F` sits between them in the title gradient. The status colours come from the site:
`#8FD694` sent, `#E0A060` held, `#EE8A72` lost.

Display type is Jersey 20 and body type is Inter, the same as the rest of the family.

## The watermark is the roll alone

`assets/watermark.svg` comes from `../src/icon-mask.svg`: the face, the side and the torn end, with
no tile. The viewBox is tightened to the shape and the fill is cream. Any watermark made from the
full app icon puts a hard-edged rounded square across the slide. The watermark sits at 2.5% opacity,
anchored bottom-right and running off both edges. It is turned off on the cover, where it would look
like a shadow of the icon.

`assets/icon.svg` is a straight copy of `../src/icon.svg`. Copy it again whenever the icon changes.

## Screenshots

`shots/` holds real captures from the plugin-testing harness, taken at 1440 CSS px wide at 2× with
`~/Sites/plugin-shots/capture.mjs`. They were then cropped with
`sips --cropToHeightWidth H W --cropOffset Y 1`. An offset of `0 0` is ignored and gives a centred
crop, so use `1 1` or `Y 1`.

| File | Screen | Used |
|------|--------|------|
| `tape-destinations.png` | Tape → Destinations | slide 7, marketing page |
| `tape-destination-edit.png` | a Meta destination, with server-side switched on | marketing page |
| `tape-triggers.png` | Tape → Triggers | marketing page |
| `tape-accuracy.png` | top of Tape → Accuracy | slide 6 |
| `tape-meta-server-side.png` | the Consent / Server-side part of the Meta edit screen | spare |
| `tape-platforms.png` | New destination: the platform picker | spare |
| `tape-trigger-edit.png` | a form-submit trigger | spare |
| `tape-settings-consent.png` | the Consent section of the plugin settings | spare |

The first three are also copied to
`~/Sites/justinholt/web/images/plugins/screenshots/craft-tape/`.

The destinations and triggers were set up in the harness only for the capture and removed again
afterwards. They started from `tests/integration/demo.php` and were then renamed and added to (Google
Ads, TikTok, server-side on GA4/Meta/TikTok with `$ENV_VAR` tokens). The Accuracy figures are the
harness's real ledger from earlier test runs. Nothing was written to the database to get them. The
Events screen was skipped because every row there belongs to a destination that has since been
deleted ("Removed").

`fonts.css` is generated by `build.sh` and gitignored. Don't edit it.
