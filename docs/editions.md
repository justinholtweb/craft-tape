conversions.

## Lite — free

Six platforms in the browser, the whole Commerce funnel, custom events, Consent Mode v2 with every
supported CMP, deduplication, the event log, and both APIs. For a store whose advertising is Google
and Meta, that is a complete setup.

Lite is not a trial. The ledger records every conversion on Lite as well, so if you upgrade later
the accuracy report fills in from the day the first one was sent.

## Pro — $99

A one-off **$99**, with a **$59/year** renewal. Everything in Lite, plus:

- **Seven more platforms**, plus custom snippets and webhooks.
- **[Server-side tracking](/plugins/craft-tape/docs/server-side)**: a second copy of each conversion
  that ad blockers and closed tabs cannot stop. Refunds go server-side too.
- **Enhanced conversions and advanced matching**: hashed customer data sent with conversions, so
  platforms can match them to accounts. See [Privacy](/plugins/craft-tape/docs/privacy).
- **[Recovery and the accuracy report](/plugins/craft-tape/docs/recovery-and-reports)**, which find
  the orders the platforms never heard about and send them.
- **[Triggers](/plugins/craft-tape/docs/triggers)**: conversions from clicks, forms, scroll depth
  and time on page, set up from the control panel.

## Renewals and downgrades

The renewal buys updates, the way every Craft plugin licence does. Pro keeps working if it lapses.

If a site is switched back to Lite, nothing breaks. Pro destinations and triggers stop firing,
server-side sends, matching data and recovery stop, and **all of their configuration is left
untouched**. Switching back to Pro restores exactly what was there, and Lite destinations carry on
as before.
